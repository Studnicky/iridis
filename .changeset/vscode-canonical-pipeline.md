VS Code role schemas are the canonical color authority. The plugin resolves graph-authored roles through the core pipeline and returns the compliance disposition with emitted theme data. The package exports compact and full role-schema vocabulary names, adds the graph-authored `buttonSecondaryHover` role, and removes the private color-math tasks `DeriveVscodeUiRoles`, `ExpandTokens`, `ApplyModifiers`, and `EmitVscodeUiPalette`.

Workbench properties that serialize transparency use the VS Code alpha projection table. Transparent paints remain outside the declared contrast-pair set.
